Privacy Policy — ShortsOff

Last updated: 28 September 2026

ShortsOff is a Chrome extension that hides YouTube Shorts from the YouTube interface and redirects /shorts/* links to the standard watch view.

Data collection

ShortsOff does not collect, store, transmit, sell, or share any user data.

What the extension does

  • Identifies Shorts-related UI elements on youtube.com using CSS selectors and DOM property checks, and hides them by setting their CSS display property.
  • Detects when the user navigates to a /shorts/* URL and redirects the page to the equivalent /watch?v= URL.
  • Reads and writes a single boolean value (the on/off state of the toggle) in chrome.storage.local.

Permissions

  • storage: used only to persist the toggle state across browser sessions.
  • youtube.com host permission: required to inject the content script that hides Shorts elements and to detect /shorts/* navigation.

Data leaving your browser

None. The extension makes no outgoing network requests. No page content, no URLs, no user activity is sent anywhere.

Source code and audit

The full source code is publicly available at the project repository. Anyone can read it to verify these claims.
